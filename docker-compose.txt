Notes:

    #  Configuration	                      Purpose
    #  services	                Defines the containers Docker Compose manages.
    #  db	                    The service name. The backend will use this name to connect to PostgreSQL.
    #  image	                Uses the official PostgreSQL 17 image.
    #  container_name	        Gives the container a recognisable name.
    #  environment	            Configures the database name, username and password.
    #  ports	                Makes PostgreSQL accessible from your Windows computer.
    #  volumes	                Preserves database data between container restarts and recreations.

To rebuild and update newer versions:

   Frontend changes: docker compose up -d --build frontend
   Backend changes:  docker compose up -d --build app
   Changes to both: docker compose up -d --build
